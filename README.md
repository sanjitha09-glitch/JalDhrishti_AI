# Watershed Insight Hub

DESIGN REFERENCE: Build the UI with the visual composition of a professional geospatial command center: a dark-green left navigation sidebar, white/light main workspace, large interactive GIS map occupying the central area, KPI cards across the top, intervention-detail panel beside the map, watershed indicator cards/charts on the right, and analytical charts below the map. The dashboard should visually prioritize the GIS map and spatial intelligence rather than generic SaaS cards. Maintain a clean forest-green, white, charcoal, and restrained blue visual system. Use the supplied JalDrishti AI concept as the design direction throughout every page.

Build a professional, national-level Smart India Hackathon prototype called:

JalDrishti AI

Tagline:
“Geospatial Intelligence for Smarter Watershed Development”

Problem Statement:
SIH26015 — Application of Geospatial Techniques for visualization and analysis to interpret Geo-Coded Images to enhance Watershed Development Outcomes.

Organization:
Ministry of Rural Development
Department of Land Resources

Theme:
Agriculture, FoodTech & Rural Development

IMPORTANT:
This is NOT a normal CRUD website, generic admin dashboard, or simple GIS map viewer.

JalDrishti AI must look and behave like a serious Government/Geospatial Intelligence Decision Support System designed for watershed monitoring and assessment.

The primary objective is to integrate:
1. Geo-coded field images
2. Satellite imagery/data
3. Watershed boundaries
4. GIS thematic layers
5. Image interpretation
6. Spatial analytics
7. Before-vs-after change detection
8. Watershed development indicators
9. AI-assisted insights
10. Evidence-based decision support
11. Professional report generation

The interface should immediately communicate:
GEOSPATIAL INTELLIGENCE + WATERSHED MONITORING + AI + DECISION SUPPORT.

Do NOT make it look like a generic AI startup landing page.

==================================================
1. PRODUCT VISION
==================================================

JalDrishti AI is a geospatial intelligence platform for monitoring and analyzing watershed development activities.

The platform should allow a government officer or authorized monitoring user to:

• Select a state
• Select a district
• Select a watershed
• View the watershed boundary on an interactive GIS map
• View interventions and geo-coded field photographs
• Upload geo-coded field photographs
• Extract and display image metadata
• Associate field images with watershed/intervention locations
• Visualize satellite imagery
• Toggle thematic GIS layers
• Analyze vegetation indicators
• Analyze water-related indicators
• Compare different time periods
• Detect spatial changes
• View intervention-level observations
• Generate AI-assisted insights
• Generate a professional watershed assessment report

The system must clearly distinguish between:
OBSERVED SPATIAL CHANGES
and
CAUSAL IMPACT.

Never claim that an intervention caused a change simply because a satellite indicator changed.

Use language such as:
“Observed spatial change”
“Indicator trend”
“Detected change”
“Provisional observation”
“Requires contextual validation”
